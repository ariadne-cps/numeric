# Reduced frozen oracle sampling (remove-gmp)

The original files were certified independently. Sampling is performed only on those existing frozen rows: expected results are never recomputed from the implementation under test. The original mt19937_64 stream is consumed for every original iteration; the C++ checks skip excluded cases only after constructing and mutating the random words. Both sequential TSV readers reject missing, out-of-order, and extra rows.

* BigUnsigned power: all ten width counts, modes 0/1/2/3/7 (zero, saturation, top-bit, dense, alternate saturation) and exponents 0/1/2/8/16/17 (identities, squaring, dispatch/high-bit boundaries). Every S (irregular base) and B (1024-bit limit) row is retained. 1513 -> 373 rows (4.06x).
* BigUnsigned short division: all 36 limb-width pairs (including empty dividend/divisor, equal widths, and the 4/5-limb edge); modes 0/1/2/3/4/5/11/17/23 preserve each distinct mode%6 category plus multiple dense high modes. 864 -> 324 rows (2.67x).

A tenfold reduction is not justified for these two datasets without dropping valuable operand widths or power/boundary classes. Future independent GMP/MPFR replacements should prefer source-keyed TSV fixtures and preserve algorithm thresholds, rounding modes, operand signs, equal/unequal widths, aliasing and exceptional inputs; record per-dataset counts. This step does not claim to remove all remaining runtime GMP/MPFR uses.

* BigUnsigned B41 subtraction: source-keyed 9 structural classes at each of 11 nonzero limb widths (and canonical zero), keeping both operand directions and underflow expectations: 768 -> 100 operand pairs (7.68x). Original generator state reproduced exactly (the first five draws were cross-checked against C++ std::mt19937_64), then all expected results computed independently with exact integers. Source includes no GMP in this test function.

* Integer B18: 1,700 randomized GMP differential repetitions -> 170 frozen exact arithmetic sources/results (10x). Integer B17: 2,500 repetitions -> 250 frozen exact arithmetic/shift cases (10x). Source streams use the original std::mt19937_64 seeds verified against independent compiled C++ outputs. Select rep=10*k+(7*k+3)%10; the 250 B17 samples cover every rep%130 shift count, all 8 decimal lengths, all six sign states, and 16 zero dividends. The 170 B18 samples cover all 7 decimal lengths, all sign states, and 9 zero dividends. Offline results use native exact signed integers and C++ truncation-toward-zero quotient/remainder, not Integer-under-test, GMP or MPFR. Runtime loops iterate only sampled TSV cases and check input-derived structural invariants.

* Integer B33 (square aliasing): 9 widths x 16 modes = 144 -> 9 x 8 = 72 source cases (2x); all eight unique mode%8 structures and 7/8/9-limb boundary preserved. Integer B37 (large signed power): 6 widths x 12 repetitions x 3 powers = 216 -> 6 x 4 x 3 = 72 checks (3x); retain saturation, single-top-bit, positive/negative dense, exponents 2/3/5. Integer B38 (pow3): 5 widths x 24 repetitions = 120 -> 5 x 6 = 30 (4x); all six mode%6 structures, signs and 128-limb maximum preserved. Independent exact BigInt integers produce all expected values, and the generated sources use mt19937_64 streams checked against C++ first-five draws; runtime GMP removed from these three test blocks.

* Integer B66 signed power: original 5 limb-width counts x 12 source modes x 18 exponent visits = 1080 -> 5 x 4 x 18 = 360 cases (3x). Keep each width, all 18 exponents including exact 31/32/33 and 63/64/65 transitions and four distinct structural source classes from the original standard mt19937_64 stream. Independent exact signed integer powers frozen in integer_b66.tsv. Runtime GMP removed from B66 and the now-unused local GMP RAII wrapper eliminated, fixing the previously reported -Wshadow warnings in B33/B37/B38. The separate intentional integer_from_gmp bridge-conversion constructor test remains to preserve its interface coverage.

* BigUnsigned R14 square/self-alias: 7 x 12 = 84 -> 7 x 4 = 28 (3x), retaining all seven limb widths and the four mode%4 classes. Critically, the original seeded RNG draws still occur for all 12 visits per width because subsequent GMP comparisons reuse that same engine. BigUnsigned B72 4/5-limb owning multiplication: 36 width pairs x 32 modes = 1,152 -> 36 x 8 = 288 (4x), retaining all eight mode%8 classes (saturated, zero, sparse, noncanonical-like, independent dense cases) with both operand orders and squaring. Each TSV freezes original input(s) as well as independent exact expected results; no GMP oracle calls remain in these two test blocks. Seeded source streams were checked against a separately compiled C++ std::mt19937_64 harness.

* BigUnsigned original seeded general multiplication: 6,000 -> 600 (10x). One case selected from each ten-repetition bucket by adaptive coverage of both source operand widths, low-product lengths and zero/dense classes. All 34 original widths for both operands survive (minimum 10 n-cases and 10 m-cases each), plus all 5 truncation modes; 91 cases have at least one zero operand. Original RNG replayed including all R14 source draws, and its first ten random-corpus repetitions cross-validated against independently compiled C++. Each TSV row freezes source values, full product, exact square and low-product oracle. No GMP runtime calculation remains in this 6,000-case block.

* B35 selective Karatsuba multiplication: 14 original width pairs x 32 repetitions = 448 -> 14 x 5 = 70 oracle rows (6.4x). Every 63/64/65 crossover and unbalanced pair survives. Retain original modes 0..4: saturated long carries, sparse low-only, remote high/low, alternate zero-row, dense random. Independent exact integer products frozen with original input sources in big_unsigned_b35.tsv. Runtime avoids both GMP and the original 32-iteration random generator; one oracle is parsed once for both operand orientations.

* B40 Karatsuba leaf/dispatch: 18 width pairs x 16 original repetitions = 288 -> 18 x 9 = 162 (1.78x). All eight distinct zero-row density modes plus the special saturated rep=15 survive, as do the 31/32/33 and 63/64/65 dispatch boundaries, both multiplication orientations, both truncated orientations, squaring and explicit cutoff-32 Karatsuba. Frozen independent source/product/low/square oracle in big_unsigned_b40.tsv; no GMP runtime oracle in B40.

* BigUnsigned B39 adaptive density/dispatch: 19 width pairs x 20 repetitions = 380 -> 19 x 8 = 152 (2.5x). Original repetitions 0,1,2,3,4,5,6,9 cover all seven density classes on both operands (including the right_mode remapping) and both truncated-product length branches. Preserve 63/64/65, 64/85/86, balanced/unbalanced and 128-limb limits. Original full RNG stream reproduced offline; six initial draws checked against a separately compiled C++ std::mt19937_64. Expected full product, square and low product frozen independently. No runtime GMP in B39.

* BigUnsigned B54 full products: 17 pairs x 32 = 544 -> 17 x 8 = 136 (4x). All eight pattern%8 classes, both operand orders and fused product checks retained. Original RNG state advanced for all 32 visits per pair to preserve subsequent B54 squaring inputs. Values frozen independently in big_unsigned_b54_product.tsv.

* Fixture path convention: CMake exports one absolute `ARIADNE_TEST_DATA_DIR` macro per oracle-using target (BigUnsigned, Integer, FloatAP). Each C++ test owns its TSV filename as an `inline constexpr char[]` path assembled at compile time. This preserves out-of-source and Windows test execution and removes 32 per-file CMake compile definitions. Fix B54 missing `b54_engine` declaration after conversion of its product loop; replay the full original shared generator stream before the remaining square corpus.

* BigUnsigned B54 symmetric square: 13 widths x 64 original mode visits = 832 -> 13 x 8 = 104 (8x). All eight mode%8 structural classes and 7/8/9, 31/32/33, 63/64/65/66 size transitions retained. Offline generator fully advances across the original preceding 17 x 32 product rounds and all square visits; runtime no longer consumes redundant shared RNG draws. Source/square reference pairs frozen in `big_unsigned_b54_square.tsv` using independent exact arithmetic.
