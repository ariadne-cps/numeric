## Rounded min/max

The per-symbol report showed untested NaN selections, signed-zero rules and
both orders of unequal precision. The standalone generator_floatmp_minmax
emits 648 cases. Exact small rational arithmetic first rounds each source
to its input precision (nearest/even), selects min/max with the documented
NaN and zero rules, then independently rounds to the smaller precision in
each of four modes. No Numeric, GMP, MPFR or host floating-point arithmetic
supplies expected results. A separate Python Fraction witness enumerating
representable values reproduces every row.

The consumer checks value, kind, sign (including zero), result precision,
and preservation of the ambient rounding mode. This covers observable
behavior, not merely execution. All inputs use the public API.
